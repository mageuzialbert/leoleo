# Leoleo Farms website project

This folder holds the research, design brief, and English-language Next.js public website for Leoleo's three projects: pig farming and the meat shop, Pili Pili chili farming, and Kwanza Coffee.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`. Use `npm run build` to check a production build.

The first release has no backend. The contact form composes an enquiry for the verified farm WhatsApp account at **+255 652 620 724** and sends the visitor to WhatsApp to review and send it. It does not save form data. The meat shop and Kwanza Coffee have their own direct phone links on the Contact page.

- [Website plan](WEBSITE_PLAN.md): proposed site structure, visual direction, and build approach.
- [Business facts](research/notes/business-facts.md): confirmed details and source notes.
- [Photo catalog](research/notes/photo-catalog.md): image candidates and publishing cautions.
- `public/images/`: selected farm and café photographs, the supplied meat photo and logo, the director portrait, the farm team photograph, and rendered certificate previews. Certificates open in an image zoom viewer. Confidential source PDFs remain in the ignored research archive and are not publicly served.
- [Director and certifications](research/notes/director-and-certifications.md): supplied biography, company incorporation and three Tanzania Meat Board registration documents.
- [Draft brand copy](research/notes/brand-copy.md): the requested short stories, vision and mission, with editorial notes.
- [Instagram research](research/instagram/source-notes.md): source posts for the farm's 2024 starting year, habanero crop and Mboni Ya Vijana presentation.

The original Word proposal and text extraction, 31 WhatsApp photos, supplied image originals, and generated preview screenshots remain in the local project folder and are excluded from Git. The proposal contains private pricing and terms. It informs the business brief; it is not public website copy or an agreed specification for this website.
